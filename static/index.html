🔗 Nhờ trợ lý tải YouTube

YouTube chặn server (không tải trực tiếp được). Dán link vào đây, hệ thống sẽ tự tải giúp bạn trong vài phút, MP3 sẽ xuất hiện trong Thư viện MP3 ở trên 👆

🍪 Cookies YouTube

YouTube chặn server tải video (báo lỗi "not a bot"). Để sửa:
1️⃣ Cài extension "Get cookies.txt LOCALLY" trên Chrome
2️⃣ Mở youtube.com (đăng nhập rồi càng tốt) → bấm icon extension → Export → được file cookies.txt
3️⃣ Upload file đó ở dưới 👇 (chỉ cần làm 1 lần, cookies dùng được vài tuần)
